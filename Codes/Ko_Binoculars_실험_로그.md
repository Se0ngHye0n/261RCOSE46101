## 1. 모델 교체 실험 (Ko-Binoculars) ✅ 성공

### 목적
Binoculars의 Observer/Performer를 한국어 모델로 교체하여 성능 향상 확인

### 결과

| 모델 쌍 | 학습 | ROC-AUC | PR-AUC | Recall | F1 |
|---------|------|---------|--------|--------|----|
| Falcon-7B + Instruct (원본) | X | 67.54 | 41.00 | 66.48 | 55.27 |
| Polyglot-Ko 1.3B + 3.8B | X | 96.62 | 66.65 | 75.60 | 65.27 |
| EXAONE 2.4B + 7.8B | X | 94.41 | 70.46 | 79.74 | 82.95 |
| Qwen2.5-7B base + instruct | X | 93.79 | 51.75 | 84.60 | 83.19 |
| Qwen2.5-3B base + instruct | X | 95.40 | 52.69 | 86.56 | 85.65 |
| KatFishNet (Punct.) | O | 97.57 | 78.99 | 62.65 | 94.88 |

### 결론
- 한국어 모델로 교체만으로 ROC-AUC 67.54 → 96.62 (약 +29%p)
- 제로샷(학습 불필요)임에도 supervised KatFishNet에 근접하는 성능
-  EXAONE은 transformers 라이브러리 버전 충돌로 이후 실험에서 사용 안함

## 2. 토크나이저 Fertility 분석 ✅ 유의미한 발견

### 목적
모델 교체가 왜 효과적인지 이론적 근거 제시

### 결과

| 모델 | Fertility (tokens/char) | Avg Tokens | ROC-AUC |
|------|------------------------|------------|---------|
| Falcon-7B | 2.133 | 1053.4 | 67.54 |
| Polyglot-Ko 1.3B | 0.533 | 248.7 | 96.62 |
| Qwen2.5-7B | 0.679 | 314.3 | 93.79 |
| Qwen2.5-3B | 0.679 | 314.3 | 95.40 |

### 상관계수
- **Fertility vs ROC-AUC: r = -0.9986, p = 0.0014** (통계적으로 유의미)
- Fertility vs F1: r = -0.7219, p = 0.2781 (유의미하지 않음)

### 결론
- 토크나이저가 한국어를 효율적으로 처리할수록(fertility↓) 탐지 성능↑
- Falcon은 한국어 1글자당 토큰 2개 이상 → 비효율적
- Polyglot-Ko는 약 2글자당 토큰 1개 → 효율적
- F1은 fertility 외에 모델 아키텍처 등 다른 요소도 관여

## 3. 형태소 가중치 (MW-Binoculars) ❌ 실패

### 목적
한국어 교착어 특성을 반영하여 실질 형태소(명사/동사)에 높은 가중치, 기능 형태소(조사/어미)에 낮은 가중치 적용

### 수식

$$
MW-B(X) = W-PPL(M1, X) / W-XPPL(M1, M2, X)
$$
$$
W-PPL = -Σ wi · log P(xi|x<i) / Σ wi
$$

- α (실질 형태소) = 1.0
- β (기능 형태소) = 0.1 ~ 1.0
- γ (구두점) = 0.1

### 형태소 분류 기준
- **실질(Content)**: NNG, NNP, NNB, NR, NP, VV, VA, VX, MAG, MAJ, MM, IC
- **기능(Functional)**: JKS~JKQ, JX, JC, EP, EF, EC, ETN, ETM, XPN, XSN, XSV, XSA
- **구두점(Punct)**: SF, SP, SS, SE, SO, SW 및 기타

### 실험 결과 (Qwen2.5-3B, 30개 샘플)

| Config | H_mean | AI_mean | Gap |
|--------|--------|---------|-----|
| baseline(1,1,1) | 1.0904 | 0.8289 | +0.2614 |
| content↑(2,1,1) | 1.1084 | 0.7580 | +0.3504 |
| func↓(1,0.3,1) | 1.0994 | 0.7634 | +0.3359 |
| punct↓(1,1,0.1) | 1.0616 | 0.8231 | +0.2385 |
| content↑func↓(2,0.3,1) | 1.1183 | 0.7645 | +0.3537 |

5개 샘플에서는 일부 개선이 보였으나, **30개로 늘리면 baseline과 차이 없음**

### 실패 원인
- PPL/XPPL 비율 구조에서 가중치가 분자·분모에 동시 적용 → **상쇄 효과**
- 비율 기반 스코어에서는 가중치 조절이 최종 값에 미미한 영향

### 검증
- MW(α=1, β=1, γ=1)과 Original의 diff < 0.0003 → 수식 구현은 정확
- 가중치 전략 자체의 한계

## 4. 어절 단위 Binoculars ❌ 실패

### 목적
토큰 단위 대신 어절(띄어쓰기) 단위로 PPL/XPPL을 계산하여 한국어 구조 반영

### 두 가지 버전
- **v1 (어절별 합산)**: 어절 내 토큰의 CE를 합산 후 어절 수로 나눔
- **v2 (어절별 평균의 평균)**: 어절 내 토큰의 CE 평균을 구한 뒤 어절들의 평균

### 결과 (30개 샘플)

| Method | H_mean | AI_mean | Gap |
|--------|--------|---------|-----|
| Token-level | 1.0904 | 0.8290 | +0.2614 |
| Eojeol-sum (v1) | 1.0904 | 0.8289 | +0.2614 |
| Eojeol-avg (v2) | 1.1098 | 0.8375 | +0.2723 |

### 전체 데이터 결과 (94개 Human + 전체 LLM)

| Method | LLM | H_mean | AI_mean | Gap |
|--------|-----|--------|---------|-----|
| Token | Solar | 1.0810 | 0.8882 | +0.1927 |
| Eojeol-avg | Solar | 1.1137 | 0.9319 | +0.1818 |
| Token | Qwen2 | 1.0810 | 0.9867 | +0.0942 |
| Eojeol-avg | Qwen2 | 1.1137 | 1.0008 | +0.1128 |
| Token | Llama3.1 | 1.0810 | 0.9636 | +0.1173 |
| Eojeol-avg | Llama3.1 | 1.1137 | 1.0036 | +0.1101 |

### 실패 원인
- v1은 수학적으로 토큰 평균과 동일 → 차이 없음
- v2는 LLM에 따라 좋아지기도(Qwen2) 나빠지기도(Solar) → 일관성 없음

## 6. 문장별 분산 (Sentence Variance) ❌ 실패

### 목적
"사람 글은 문장마다 복잡도 편차가 크고, AI 글은 균일하다"는 가설 검증

### 분산 비교 (30개 샘플)

| Group | Mean Score | Std (분산) |
|-------|-----------|-----------|
| Human | 0.9473 | 0.1280 |
| AI (Solar) | 0.8393 | 0.1042 |
| AI (Qwen2) | 0.9164 | 0.1038 |
| AI (Llama3.1) | 0.9127 | 0.1152 |

→ 가설 성립: Human 분산 > AI 분산 (일관됨)

### 2D 분류 결과 (Bino + Sentence Std, 394개)

| Method | ROC-AUC |
|--------|---------|
| Bino only | 91.70 |
| Bino + Variance (2D) | 91.70 |
| **Δ** | **-0.01** |

### 실패 원인
- 분산의 절대적 차이가 너무 작음 (0.1280 vs 0.1042)
- coefficient도 std가 -0.2652로 bino(-2.3275) 대비 변별력 부족

## 7. 토큰 레벨 통계량 탐색 ⚠️ 부분적 발견

### 목적
문장 레벨이 아닌 토큰 레벨에서 다양한 통계량의 변별력 탐색

### Human vs AI 비교 (30개 샘플)

| Feature | Human | AI | Diff | Ratio |
|---------|-------|-----|------|-------|
| bino | 1.0908 | 0.8291 | +0.2617 | 1.315 |
| ce_std | 1.6562 | 1.4199 | +0.2363 | 1.166 |
| **nll_std** | **2.4355** | **1.7021** | **+0.7334** | **1.431** |
| ce_skew | 0.3921 | 0.8252 | -0.4331 | 0.475 |
| nll_max | 11.9766 | 8.3984 | +3.5781 | 1.426 |
| ce_range | 6.2578 | 6.2109 | +0.0469 | 1.008 |

### 발견
- **nll_std (Ratio 1.431)**: 가장 높은 변별력. 사람은 토큰별 NLL 편차가 큼
- ce_skew (Ratio 0.475): AI 글은 CE 분포가 오른쪽 치우침

### 피처 결합 결과 (394개, in-domain)

| Combo | ROC-AUC | Δ vs bino |
|-------|---------|-----------|
| bino_only | 91.70 | +0.00 |
| **bino+nll_std** | **96.38** | **+4.68** |
| bino+ce_skew | 91.73 | +0.03 |
| bino+nll_std+ce_skew | 96.54 | +4.84 |

→ nll_std가 핵심 피처, ce_skew는 기여 미미

### ⚠️ 주의
- 위 결과는 train/test 분리 없는 in-domain → 과적합 가능성
- Cross-domain에서는 로지스틱 회귀 기반 결합이 불안정 (abstract→others에서 붕괴)

| Original | 1.0904 | 0.8290 | +0.2614 |
| Normalized | 1.1635 | 0.9668 | +0.1967 |

### 실패 원인
- 전처리하면 Human과 AI의 차이가 오히려 줄어듦
- 형태소를 건드리면 텍스트가 단순해져서 둘 다 예측하기 쉬워짐
- **역설적 발견: 조사/어미 같은 기능 형태소가 오히려 탐지에 중요한 정보를 포함**

## 9. 다중 제로샷 메트릭 결합 (학습 없는 Fusion) ⚠️ 부분적 성공

### 목적
Binoculars + NLL 분산 + Log-Rank + Entropy 등을 학습 없이 결합

### 단독 메트릭 AUC (전체 데이터)

| Metric | AUC |
|--------|-----|
| bino | 85.70 |
| **nll_std** | **87.25** |
| log_rank | 77.98 |
| log_likelihood | 76.67 |
| entropy | NaN (overflow) |

→ **nll_std 단독(87.25)이 bino 단독(85.70)보다 높음** — 중요한 발견!

### 학습 없는 결합 (정규화 후 가중 평균)

| Combo | AUC | Δ vs bino |
|-------|-----|-----------|
| bino only | 85.70 | +0.00 |
| **bino + nll_std** | **87.95** | **+2.25** |
| bino + log_rank | 85.02 | -0.69 |
| bino + log_likelihood | 84.64 | -1.06 |
| all 4 | 84.65 | -1.05 |

→ log_rank, log_likelihood 추가 시 오히려 하락. **bino + nll_std만 유효**

### 최적 가중치 탐색

| Weight (bino:std) | AUC | Δ vs bino |
|-------------------|-----|-----------|
| 0.1 : 0.9 | 87.70 | +2.00 |
| 0.3 : 0.7 | 88.08 | +2.38 |
| **0.4 : 0.6** | **88.11** | **+2.40** |
| 0.5 : 0.5 | 87.95 | +2.25 |
| 0.7 : 0.3 | 87.25 | +1.55 |

### 최종 수식
```
Score(X) = 0.4 · Norm(Binoculars(X)) + 0.6 · Norm(σ(NLL(X)))
```
Norm = min-max 정규화, σ(NLL) = 토큰별 NLL의 표준편차

## 실패 실험에서 얻은 인사이트

### 왜 Binoculars 수식 변형이 어려운가
1. **비율 구조의 견고성**: PPL/XPPL 비율에서 가중치를 곱하면 분자분모가 상쇄
2. **차이 기반(PPL - XPPL)으로 바꾸면**: 텍스트 길이/도메인에 따라 스케일이 달라져 임계값 깨짐
3. **입력 전처리를 바꾸면**: 텍스트가 단순해져서 Human-AI 차이 축소

### 한국어 특성 관련 발견
- **기능 형태소(조사/어미)가 탐지에 중요**: 제거하면 성능 하락
- **한국어 언어 특징(품사 비율 등)은 도메인 의존성이 높음**: cross-domain 일반화 실패
- **토크나이저 fertility가 성능의 핵심 결정 요인**: r = -0.999
